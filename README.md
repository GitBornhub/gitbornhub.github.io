# 📝 博客维护与内容修改指南

本博客采用单文件集成设计，所有的内容、样式和逻辑均在 `index.html` 中。修改内容时，请使用文本编辑器打开该文件并参考以下说明。

---

## 🚀 内容更新 (JavaScript 部分)

定位到文件末尾 `<script>` 标签内的 `blogData` 数组，这是存放所有文章的地方。

### 1. 添加/修改文章

每篇文章是一个大括号 `{}` 包裹的对象。

* **添加文章**：复制现有块并粘贴，确保项之间用逗号 `,` 分隔。
* **正文换行**：在 `content` 字段中使用 `<p>` 标签。
* **正文小标题**：使用 `<h2>` 标签，样式已预设。

```javascript
// 示例：文章数据结构
{
    id: 1,
    title: "这里是文章标题",
    image: "图片链接 (建议 800x600 或更高)",
    date: "2024-05-20",
    content: `
        <h2>小标题内容</h2>
        <p>这里是第一段内容...</p>
        <p>这里是第二段内容...</p>
    `
},

```

### 2. “关于我”内容修改

搜索 `id="about-view"` 所在的 HTML 代码块，直接修改 `<h1>` 和 `<p>` 标签内的文字即可。

---

## 🎨 视觉与样式自定义 (CSS 部分)

定位到文件顶部的 `<style>` 标签，修改 `:root` 变量可快速改变全局风格：

| 修改目标 | 搜索关键词 | 操作说明 |
| --- | --- | --- |
| **主色调** | `--primary` | 修改十六进制颜色（如 `#4a90e2`）控制标题颜色 |
| **渐变背景** | `--gradient` | 修改 `linear-gradient` 中的颜色值控制按钮和 Logo |
| **全站背景图** | `body { background: url` | 替换括号内的 URL 链接更换背景图 |
| **毛玻璃透明度** | `--bg-overlay` | 修改 `rgba` 最后的数值（0-1）控制背景遮罩深浅 |
| **卡片宽度** | `.blog-grid` | 修改 `minmax(300px, 1fr)` 调整每行显示的卡片数量 |

---

## ⚙️ 基础信息修改

* **网站 Logo**：搜索 `class="logo"`，修改 `MY BLOG` 为你的名字。
* **浏览器标签标题**：修改文件最顶部的 `<title>` 标签文字。
* **默认背景图**：代码目前使用的是 `picsum.photos` 随机自然图片，若需固定图片，请替换 `background-size: cover;` 上方的 URL。

---

## ⚠️ 避坑指南

1. **语法符号**：在 `blogData` 中新增文章时，注意每篇文章的大括号 `{}` 之间必须有逗号 `,`。
2. **反引号**：`content` 字段内容建议包裹在反引号 ``` (Tab键上方) 中，这样支持多行书写且不会因单引号冲突导致报错。
3. **图片防掉链**：如果使用外部链接，请确保图片开启了跨域允许或使用稳定图床。
