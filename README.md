# 📝 博客更新使用说明

## 文件结构

你的 GitHub Pages 仓库需要包含以下文件：

```
你的仓库/
├── index.html       （主页面文件）
└── posts.json       （博客数据文件）
```

---

## 🎯 如何添加新文章

### 步骤 1：打开 posts.json 文件

找到 `posts.json` 文件并用文本编辑器打开（推荐使用 VS Code、Notepad++ 等）

### 步骤 2：添加新文章数据

在 JSON 数组的**开头**添加新文章（这样新文章会显示在最前面）：

```json
[
  {
    "title": "你的新文章标题",
    "excerpt": "文章摘要，简短描述文章内容，建议在 50-100 字之间",
    "image": "https://图片网址.com/image.jpg",
    "date": "2024-01-20",
    "comments": 0
  },
  // ... 其他已有的文章
]
```

### 步骤 3：保存并上传

保存 `posts.json` 文件，然后推送到 GitHub。网站会自动更新！

---

## 📋 JSON 字段说明

每篇文章包含以下字段：

| 字段 | 说明 | 示例 | 必填 |
|------|------|------|------|
| `title` | 文章标题 | `"前端开发最佳实践"` | ✅ |
| `excerpt` | 文章摘要 | `"探索现代前端开发..."` | ✅ |
| `image` | 封面图片链接 | `"https://..."` | ✅ |
| `date` | 发布日期 | `"2024-01-20"` | ✅ |
| `comments` | 评论数量 | `8` | ✅ |

## 🖼️ 如何获取图片链接

### 方法 1：使用免费图片网站（推荐）

**Unsplash**（高质量免费图片）
1. 访问 https://unsplash.com/
2. 搜索你想要的图片
3. 打开图片，点击右上角的分享按钮
4. 复制图片链接，添加 `?w=800` 参数
5. 示例：`https://images.unsplash.com/photo-xxx?w=800`

**Pexels**（另一个免费图片网站）
- 网址：https://www.pexels.com/

### 方法 2：上传到 GitHub 仓库

1. 在你的仓库中创建一个 `images` 文件夹
2. 上传图片到该文件夹
3. 使用相对路径：`"./images/你的图片.jpg"`

### 方法 3：使用图床服务

- SM.MS: https://sm.ms/
- ImgURL: https://imgurl.org/
- 路过图床: https://imgse.com/

## ✏️ 修改现有文章

### 步骤 1：找到要修改的文章

在 `posts.json` 中找到对应的文章对象

### 步骤 2：修改字段

直接修改你想改的字段：

```json
{
  "title": "修改后的标题",           // ← 修改标题
  "excerpt": "修改后的摘要",         // ← 修改摘要
  "image": "新的图片链接",           // ← 更换图片
  "date": "2024-01-20",             // ← 修改日期
  "comments": 15                    // ← 修改评论数
}
```

### 步骤 3：保存并推送

保存文件，推送到 GitHub 即可。

## 🗑️ 删除文章

直接在 `posts.json` 中删除对应的文章对象（包括花括号和逗号）：

```json
[
  {
    "title": "保留的文章",
    ...
  },
  // 删除下面这个对象 ↓
  // {
  //   "title": "要删除的文章",
  //   ...
  // },
  {
    "title": "另一篇保留的文章",
    ...
  }
]
```

## ⚠️ 常见错误及解决

### 错误 1：页面显示"加载失败"

**原因**：JSON 格式错误

**解决**：
1. 检查所有花括号 `{}` 和方括号 `[]` 是否配对
2. 检查每个字段后面是否有逗号（最后一个字段除外）
3. 检查字符串是否用双引号 `"` 包裹
4. 使用 JSON 验证工具：https://jsonlint.com/

### 错误 2：图片不显示

**原因**：图片链接失效或格式错误

**解决**：
1. 确保图片链接以 `http://` 或 `https://` 开头
2. 在浏览器中直接打开链接，检查是否能显示
3. 尝试使用其他图片链接

### 错误 3：新文章不显示

**原因**：可能是缓存问题

**解决**：
1. 清除浏览器缓存（Ctrl + F5 强制刷新）
2. 确认 GitHub Pages 已经部署成功
3. 等待几分钟（GitHub Pages 部署需要时间）

## 📝 JSON 格式检查清单

在保存文件前，检查以下几点：

- [ ] 最外层用方括号 `[]` 包裹
- [ ] 每篇文章用花括号 `{}` 包裹
- [ ] 字段名和字符串值用双引号 `""`
- [ ] 数字（如评论数）不加引号
- [ ] 每个字段后面有逗号（对象的最后一个字段除外）
- [ ] 文章之间用逗号分隔
- [ ] 最后一篇文章后面不加逗号

## 🎨 自定义网站样式

### 修改配色

在 `index.html` 的 `<style>` 标签中找到 `:root` 部分：

```css
:root {
    --primary-color: #4a90e2;        /* 主色调 */
    --gradient-start: #667eea;       /* 渐变起始色 */
    --gradient-end: #764ba2;         /* 渐变结束色 */
}
```

修改这些颜色代码即可改变整个网站的配色。

颜色代码可以在这里获取：
- https://flatuicolors.com/
- https://colorhunt.co/

### 修改背景图片

找到 `body::before` 这一行：

```css
background-image: url('https://picsum.photos/1920/1080?random=1');
```

将链接替换为你想要的背景图片。

### 修改标题文字

在 HTML 中找到：

```html
<div class="logo">我的个人博客</div>  <!-- 修改这里 -->
<h1>我的个人博客</h1>                <!-- 和这里 -->
<p>欢迎来到我的个人博客！...</p>      <!-- 和这里 -->
```

## 🚀 部署到 GitHub Pages

### 步骤 1：创建仓库
1. 登录 GitHub
2. 点击 "New repository"
3. 仓库名填写：`你的用户名.github.io`

### 步骤 2：上传文件
1. 将 `index.html` 和 `posts.json` 上传到仓库
2. 或使用 Git 命令：
```bash
git add .
git commit -m "更新博客"
git push
```

### 步骤 3：启用 GitHub Pages
1. 进入仓库的 Settings
2. 找到 "Pages" 选项
3. Source 选择 "main" 分支
4. 点击 Save

### 步骤 4：访问网站
等待几分钟后，访问：`https://你的用户名.github.io`
